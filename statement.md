# Project Statement

## Problem Statement
Controlling computer functions using traditional input devices can be inconvenient in
some situations. This project develops a real-time hand gesture controller that uses
computer vision to detect hand gestures through a camera and map them to computer
actions.

## Scope
The system focuses on real-time hand gesture detection and gesture-based computer
control using a webcam.

## Target Users
- Students
- Computer users
- Users interested in touchless interfaces

## High-Level Features
- Real-time camera input
- Hand detection
- Gesture recognition
- Gesture-to-action mapping
- Real-time feedback
